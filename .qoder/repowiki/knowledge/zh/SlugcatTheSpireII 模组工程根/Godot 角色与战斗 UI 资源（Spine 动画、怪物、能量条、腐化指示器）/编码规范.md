- 每个可交互角色（Liver/RedCat/River）在 Character/<Name>/ 下提供 N{Name}.cs 继承 NCreatureVisuals，并在 _Input 中检测 Bounds 节点包围盒后调用 creature.SetAnimationTrigger("Meow") 播放动画。
- 战斗 UI 组件统一继承 NButton，通过 [Export] string 字段暴露 res://Godot/... 纹理路径，在 _Ready() 中用 GD.Load<Texture2D> 加载并构建 TextureRect。
- 悬停提示统一通过 NHoverTipSet.CreateAndShow(this, new[] { ... }) 在 OnFocus 中显示，并在 OnUnfocus 中调用 NHoverTipSet.Remove(this) 移除。
- Spine 资源按角色/怪物分目录组织，每个目录包含 skeleton.skel、*.atlas、*.png 以及同名的 .tres 资源文件，并由独立 .tscn 场景作为入口。
- 运行时数据通过 CombatUiPatch、SlugcatData、SfxCmd 等外部静态访问，C# 脚本自身不持有持久状态，仅做视图更新与事件转发。
