模块由四个职责清晰的静态文件组成，构成模组加载期的基础设施层：
- `Entry.cs` 通过 `[ModInitializer]` 暴露 `Init()` 作为模组唯一入口，按固定顺序完成补丁注册（`RainworldPatches`）、配置注册、Godot 脚本注册、内容发现（`ModTypeDiscoveryHub`）、卡牌手牌边框规则、FMOD 音频资源映射、生命周期观察者订阅等初始化流程。
- `RainworldModConfig.cs` 使用 RitsuLib 的 `ModSettingsValueBinding<T, TProp>` 将 `RainworldModSettings` 中的布尔开关持久化到全局 JSON，并通过 `RitsuLibFramework.RegisterModSettings` 构建带本地化的设置 UI（general/monster/event 三个 section）。
- `Keywords.cs` 集中声明所有自定义 `CardKeyword`，每个关键字以 `[RegisterOwnedCardKeyword]` 特性标注并配合 `ModContentRegistry.GetQualifiedKeywordId(Entry.ModId, name)` 获取实例，供其他模块通过 `RainworldKeywords.*` 常量引用。
- `Tools.cs` 提供面向卡牌与战斗的静态辅助方法（如随机 Spear 发放、Corrupt 转换、WorkReport、BackToHand、Yinlei 伤害计算），统一通过 STS2 Core 的 `CardCmd`/`CreatureCmd`/`VfxCmd`/`PowerCmd` 等命令 API 执行副作用。
依赖方向单向向外：本模块仅依赖 `MegaCrit.Sts2.Core`、`STS2RitsuLib` 及游戏内类型，不被业务逻辑反向依赖，是其他 `Rainworld.Scripts.*` 子命名空间的公共基座。
