- 自定义卡牌关键词统一在 `RainworldKeywords` 类中以只读静态字段暴露，并通过 `[RegisterOwnedCardKeyword]` 特性 + `ModContentRegistry.GetQualifiedKeywordId(Entry.ModId, name)` 获取实例。
- 可配置开关采用 `ModSettingsValueBinding<RainworldModSettings, bool>` 模式：为每个属性创建独立 binding，再通过 `public static bool X { get => binding.Read(); set { binding.Write(value); binding.Save(); } }` 暴露读写接口。
- 初始化流程集中在 `Entry.Init()` 中按固定顺序调用 RitsuLib 提供的注册 API（补丁、配置、Godot 脚本、内容发现、音频、生命周期观察器等）。
- 战斗/卡牌副作用统一通过 STS2 Core 的命令式 API（`CardCmd`、`CreatureCmd`、`VfxCmd`、`PowerCmd`、`CardPileCmd`）在 `Tools` 静态类中封装，避免直接操作内部状态。
