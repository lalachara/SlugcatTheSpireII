本目录是 STS2 模组的顶层工程容器，负责把两个子模块（scripts_core 提供 C# 运行时逻辑，godot_assets 提供 Spine/场景/纹理等 Godot 资源）拼装成游戏可加载的模组：
- mod_manifest.json 声明模组 id、版本、依赖（STS2-RitsuLib ≥ 0.4.41）以及 has_pck=true、has_dll=true，使 STS2 同时加载打包资源与编译后的 DLL。
- project.godot 启用 Godot 4.5 + C# + Mobile 渲染后端，并将 dotnet assembly_name 设为 demo，对应 .csproj 输出产物。
- SlugcatTheSpireII.csproj 引用 sts2.dll、0Harmony、Steamworks.NET 与 STS2-RitsuLib，并通过 <Content Include="Godot\..."/> 将 godot_assets 下的场景、纹理、音频（FMOD .bank + GUIDs.txt）与 localization JSON 一并打入 PCK；PostBuildEvent 自动把编译产物复制到 STS2 mods 目录并同步 FMOD 资源。
- scripts_core 中的 C# 入口在运行时通过 STS2/RitsuLib 钩入游戏生命周期，读取同工程内 localization 与 Godot 资源完成角色、卡牌关键词与战斗 UI 的注入。
